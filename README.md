# 大股东公告雷达（ASX substantial holder tracker）

点一下按钮，自动抓取 ASX 上的大股东公告（Becoming / Change / Ceasing），只保留关注名单里的申报方（10 家主动基金 + 13 家养老金）的记录，在网页下方汇总成表格。扫描版 PDF 会用 OCR 文字识别读出来。网页可以添加到手机桌面，像 App 一样打开。

部署交给 AI 或自己动手，请看 `DEPLOY.md`。下面是日常使用说明。

## 工作方式

```
网页按钮 ──(GitHub API)──> GitHub Actions 运行 scraper/scrape.py
                                 │
                                 ├─ 读取 ASX“今日公告”和“上一交易日公告”全市场列表
                                 ├─ 挑出标题含 substantial holder / holding 的公告
                                 ├─ 下载新公告的 PDF，读前两页：申报方、目标公司、持股比例、变动日
                                 ├─ 全部结果存进 data/all_notices.json
                                 └─ 按关注名单筛选，生成 data/notices.json
网页读取 data/notices.json ──> 显示表格
```

浏览器不能直接抓 ASX 网站（跨域限制），所以抓取放在 GitHub Actions 里做，网页只负责“按按钮”和“显示结果”。

**关于“近两周”**：抓取只在你点“抓取最新公告”时运行。每次会读 ASX 的当日/上一交易日公告列表，同时从 ASX 网站自己用的全市场公告接口往前翻（约 1 万条，大约两三周），把没点按钮那几天的大股东公告补回来。所以一两周点一次也不会漏；超过两三周没点，更早的就补不回来了。白天点的话，当天之后发的公告这次读不到（ASX 晚上 8 点多还在发），页面会提示“今天只抓到几点”，之后再点一次会自动补全。

## 表格怎么看

- **类型**：新进大股东（首次超过 5%）、持股变动（每变动 1% 以上）、退出大股东（跌破 5%）。
- **持股比例**：变动类显示“之前 → 现在”，绿色是增持，红色是减持。
- **可信度**：
  - 不显示：从公告 PDF 的申报方名称直接认出来的，最可靠。
  - 中：PDF 里没能单独读出名称，是在公告第一节的文字里找到的。
  - 低：PDF 读不出文字，只根据公告标题末尾的 “from XXX” 判断。
  中和低建议点开原文核对。

持股比例和变动日都是从 PDF 文字里自动识别的，可能有误，以原文为准。

## “操作解读”怎么看

每条公告多了一个“操作解读”标签，点开能看到理由。它回答的是：这家基金在这只股票上，这次大概是在干嘛。

程序看三样东西：
1. **公告里的硬数字**：持股比例和持股数量的前后变化。比例降了但股数没变，说明是公司增发把它摊薄了，它其实没卖。
2. **公告附件里的逐笔买卖**：什么时候买卖、多少股、什么价、是场内交易还是配售/借贷/划转。
3. **当时的股价位置**（取 ASX 的日线）：买卖前涨了还是跌了，在一年区间的高位还是低位。

4. **公司同期发生的事**（看这家公司近 6 个月的公告标题）：有没有融资配股、业绩、收购、回购。
   例如买入量比全市场成交量还多、公司又刚公告融资，那多半是认购新股，不是在市场上抢筹。
5. **它的买入成本**（程序把每份公告里的买卖记下来慢慢攒）：卖出价比成本高是赚钱卖，低是亏钱卖。
6. **横向比较**：同一家基金前后三周在别的股票上是不是也在卖（都在卖更像应付赎回）、是不是这边卖那边买（换股）；
   同一只股票上名单里别的基金是同向还是反向。这些会显示成小标签：整体减仓、整体加仓、换股、多家同向、有人反向、参与融资、收购相关、业绩后。

再结合基金类型（主动选股 / 多空对冲 / 战略家族 / 养老金 / 平台多经理）给出标签，例如：
新进建仓、加仓越过 5% 线、逢低加仓、顺势加仓、高位减仓像获利了结、低位减仓像止损、边买边卖像调仓、
被动稀释、证券借贷变动、小幅卖出刚好跌破 5% 线、收购消息后买入像并购套利。

成本价是从 2026 年 10 月开始攒的，刚开始只有少数公告用得上，用得越久越全。

注意：**这是推断，不是基金自己的说法**。公告里从来不写买卖原因；“把握：低”的尤其要自己点开原文看。
养老金和平台类的持仓是很多组合加在一起的，信号比主动基金弱。

## 修改关注名单

编辑 `scraper/watchlist.json`：

- `group`：网页上的分组，现在有“主动基金”和“养老金”两组，网页可以按组筛选。
- `aliases`：申报方在公告 PDF 里出现的全称，用来匹配。养老金申报时用的是受托公司名，例如 Cbus 是 “United Super Pty Ltd”、HESTA 是 “H.E.S.T. Australia”、CFS 是母公司 “Superannuation and Investments HoldCo”。
- `hints`：公告标题末尾 “from XXX” 里可能出现的缩写。
- `noise_hints`：投行、托管、指数基金这类噪音申报方，标题里出现这些缩写的公告直接跳过，不下载 PDF。

改完后下一次运行，最近 35 天内已抓过的公告也会按新名单重新匹配，不用重新下载。网页上方的格子会自动跟随名单。

**关于养老金**：只看得到养老金自己操盘的那部分。交给外部基金经理管理的钱，超过 5% 时由基金经理以自己的名义申报。另外门槛是 5%，所以基本只看得到中小盘股票。

**关于扫描件**：约一成公告是扫描的图片 PDF。抓取时会用 tesseract 做文字识别（OCR），网页上标着“扫描件·文字识别”，识别出来的数字可能有错，请点开原文核对；字迹太模糊或手写的仍然读不出。

## 放到手机桌面

- **iPhone**：用 Safari 打开网页地址 → 分享 → 添加到主屏幕。
- **Android**：用 Chrome 打开网页地址 → 菜单 → 添加到主屏幕（或“安装应用”）。

从桌面图标打开后，要在“GitHub 设置”里再填一次令牌，因为令牌只保存在各自设备和浏览器里。

## 常见问题

- **按钮提示令牌无效或权限不足**：令牌需要对这个仓库有 Actions 读写权限、Contents 只读权限。
- **红色提示“没有读到 ASX 公告列表”**：ASX 网站当时不可用或改版了。点状态栏里的日志链接查看原因；如果连续几天都这样，需要按 `DEPLOY.md` 的排错步骤调整解析代码。
- **页面一直提示缺交易日**：有几个交易日没点抓取，ASX 只公开当天和上一交易日的列表，错过的日子补不回来。之后每隔一两个交易日点一次即可。
